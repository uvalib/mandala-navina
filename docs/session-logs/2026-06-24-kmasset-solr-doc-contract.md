## A fourth path the code surfaces

Your `spike_solr_demo` module ships `search_api.server.kmassets.yml` + `search_api.index.kmassets.yml` — Drupal already has a **search_api connection to the kmassets index** (Spike 2, read-side). search_api_solr can also *write* Drupal entities into a Solr index natively.
